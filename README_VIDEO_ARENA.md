## 1. Core Paradigm: Intransitive Mutable Catalysts & Zero-Imba RPG Party-Building

Conventional game engines and AI simulators suffer from two opposite failure modes:
1. **Static Hierarchy ("Imba" Dominance):** One dominant entity or rule unilaterally defeats or modifies others while remaining permanently immune itself ($A > B > C$).
2. **Symmetric Chaos ("Brown Mud" Blending):** Every entity simultaneously modifies every other entity on the same frame, causing 3D-DiT Cross-Attention (`attn2`) to collapse into an unstructured texture soup.

**Exocortex 3D-DiT** solves this by synthesizing **Warren McCulloch's Neural Heterarchy** (*McCulloch, 1945* [[1]](#ref-1)), **Stuart Kauffman's Reflexively Autocatalytic Sets** (*Kauffman, 1986* [[8]](#ref-8)), and **Winfree's DNA Strand Displacement Cascades** (*Soloveichik et al., 2010* [[9]](#ref-9)) into a single universal primitive: the **Mutable Working Memory Catalyst (`WM-Agent`)**.

1. **Local Catalytic Invariance (Asymmetry Within a Single Reaction):**
   In any active reaction $e_{\text{cat}}(s_c) + e_{\text{sub}}(s_a) \longrightarrow e_{\text{cat}}(s_c) + e_{\text{sub}}(s_b)$, the **Catalyst** ($e_{\text{cat}}$) **is not consumed and is not mutated back by the substrate** (`INV[CAT]`). It acts as an unyielding morphogenetic field that drives the **Substrate** ($e_{\text{sub}}$) across a phase transition $s_a \to s_b$.
2. **Global Intransitive Mutability (Zero "Imba" Across the Ring):**
   No entity is an invincible "imba". Every catalyst that is invariant in Reaction $k$ **becomes the mutable substrate in Reaction $m$** when acted upon by its own upstream counter-catalyst:

## 3. Intra-Block Realtime Working Memory Steering (`live_pos_emb_fn`) & Variance-Preserving High-Radius Morphing (`--wm-radius 0.84`)

In `neuro_controller.py`, `neuro_solver_stepper.py`, and `neuro_engine.py`:

   * Because it rotates the *same* base prompt `pos_emb` within its tangent cone while strictly preserving token norms (`ref_norms`), objects (mountains, cliffs, crystals, creatures) remain 100% sharp while responding in real time to cortical phase shifts during block generation.
2. **Variance-Preserving Context Blending (Eliminating Lighting Flicker at `--wm-radius 0.84`):**
   When conditioning on `n_cond` context latent frames (`anchor_prefix_5d`) with a high working memory radius (e.g., `wm_radius = 0.84`, where `tail_lock = 0.88 - 0.42 * 0.84 = 0.527`), a naive linear blend $w \cdot \mathbf{z}_{\text{anchor}} + (1 - w)\cdot \boldsymbol{\epsilon}$ reduces the variance of the conditioning frame to $w^2 + (1-w)^2 \approx 0.501$ ($\sigma \approx 0.707$), causing a brightness flash at every block boundary.

   $$\mathbf{z}_{\text{cond}} = \frac{w\,\mathbf{z}_{\text{anchor}} + (1 - w)\,\boldsymbol{\epsilon}_{S^3}}{\sqrt{w^2 + (1 - w)^2}}$$
