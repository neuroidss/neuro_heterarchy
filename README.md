## 2. Pure Amodal Neocortical Architecture (`neuro_amodal_engine.py`)

### 2.1 The 96,000-Mode Full-Rank Tensor (No Dimensionality Loss)
The raw mesoscopic electroencephalographic field is ingested into PyTorch tensor buffers at 250–500 Hz. For 16 channels, all $\binom{16}{2} = 120$ unique bipolar pairs are computed without zero-lag volume conduction using the **Corrected Imaginary Phase-Locking Value ($ci\text{PLV}$)**.
The amodal state tensor preserves the full spectrum of cortical dynamics:
$$\mathcal{W}_{\text{WM}} \in \mathbb{R}^{5 \text{ (regions)} \times 5 \text{ (rhythms)} \times 32 \text{ (phase slots)} \times 120 \text{ (dipoles)}} = 96,000 \text{ continuous modes}$$

### 2.2 Causal Heterarchy: 5 Regions & Inter-Laminar Loops
Grounded in Vernon Mountcastle, *Hawkins et al. (2017; 2025)*, and *Bastos et al. (2018)*, the architecture executes five coupled `AmodalMontyColumnGPU` microcircuits. By executing heavy synaptic matrices ($\mathbf{W}_{\text{out}}$, $\mathbf{W}_{\text{topdown\_sdr}}$) in pure `bfloat16`/`float16` precision natively on CUDA, the entire 5-region heterarchy requires `< 400 MB` of VRAM.
* **Temporal Receptive Windows (TRWs):**
  * $\tau_{\text{FCz}} = 0.04\text{ s}$ — Instantaneous motor action and gamma dynamics (SMA).
  * $\tau_{\text{F3}} = 0.35\text{ s}$ — Structural ON-subspace representation.
  * $\tau_{\text{F4}} = 0.35\text{ s}$ — Contextual OFF-subspace representation.
  * $\tau_{\text{AFz}} = 1.20\text{ s}$ — Relational scene topology & composition ($A \supset B$).
  * $\tau_{\text{Fpz}} = 5.00\text{ s}$ — Meta-rules and macro-scenario shifts.

### 2.3 Non-Linear Hierarchical Order: Nested Oscillatory Dynamics
1. **Linguistic-Scale Temporal Embedding (*Ding et al., 2016*):** Slower rhythms hierarchically phase-modulate faster rhythms.
2. **2D Orthogonal Rank Geometry (*Fan et al., 2024*):** Sequence ranks factorize into a 2D near-orthogonal manifold ($\text{LGA} \approx 90^\circ$).
3. **Working Memory 2.0 Structural Stability (*Miller et al., 2018*):** Deep-layer Beta oscillations ($13\text{--}30\text{ Hz}$) act as an inhibitory gate.
4. **89.5 Hz Dickey Ripple Causal DAGs (*Dickey et al., 2022*):** High-frequency ripples ($70\text{--}100\text{ Hz}$) establish non-linear causal graphs via zero-lag phase consistency.

## 3. Generative Video World Models (`video_world_server.py`)

### 3.1 Smart VRAM Allocation (Zero Disk Clutter)
NeuroCanvas automatically scales its memory footprint based on available GPU VRAM. The system keeps a massive language model permanently in memory for on-the-fly zero-delay concept mapping:

| Hardware | VRAM | T5-XXL Strategy | 3D-DiT Transformer |
| :--- | :--- | :--- | :--- |
| **RTX 5090 / A100** | **32+ GB** | Pure `bfloat16` resident in VRAM (~9.5 GB) | Native `bfloat16` (~4.0 GB) |
| **RTX 4090** | **24 GB** | Pure `bfloat16` resident in VRAM (~9.5 GB) | Native `bfloat16` (~4.0 GB) |
| **RTX 3060** | **12 GB** | **4-bit NF4 Resident (~6.4 GB)** | **FP8 Layerwise Casting (~1.9 GB)** |

*Note: The RTX 3060 12GB setup optimally balances memory, using ~8.5 GB for the heavy models and leaving ~3.5 GB of pure headroom for the `neuro_amodal_engine`.*

### 3.2 Tabletop In-Context Reasoning & Chain-of-Frame (VR-Bench Parity)
Following the benchmark insights of *VR-Bench (arXiv:2511.15065)*, video models reason across space and time through **Chain-of-Frame (CoF)** dynamics rather than static next-token prediction. We explicitly resolved the "Rubber-Band Anchor" effect that previously teleported avatars back to their spawn coordinates:
1. **Genesis Phase ($t=0$):** Full denoising establishes the foundational environment from the lore's architectural description (e.g., drawing the 5x5 maze and exit portal).
2. **Tabletop Streaming Phase ($t > 0$):** The system continuously references `last_frame_gpu` as the base latent for the next sequence. Background architecture is preserved through cortical Beta inhibition ($13\text{--}30\text{ Hz}$), while kinematic spatial gradients computed by the FCz region allow the avatar to physically traverse the corridors seamlessly.

```
  [FreeEEG16-alpha2 / FreeEEG24 Sensor Array] (26 mm Circular Scalp Array)
                         │
                         ▼ (BLE 24-bit ADC Packets @ 250/500 Hz)

                         │
                         ▼ (LSL Multi-Stream Protocol)
  [neuro_amodal_engine.py] (Direct-to-VRAM GPU Spectral Frontend)
                         │
                         ▼ (Native CUDA IPC Storage Sharing)
  [video_world_server.py / neuro_heterarchy_diffusion.py / musicgen_server.py]
```

* **Physical Sensors:** High-density circular arrays ($26\text{ mm}$ footprint, $5.38\text{ mm}$ electrode pitch).
* **Zero-Allocation Ingestion (`direct_ble_to_lsl.py`):** Unpacks 24-bit signed integers via bitwise shifts into preallocated C-types arrays without garbage-collection pauses.
* **Sub-Microsecond Latency:** POSIX shared memory buffers and CUDA IPC eliminate PCIe bus bottlenecks.
